## Status

## Overview

The Portfolio Website is Kushagra's personal website designed to showcase his projects, skills, achievements, certifications, and experience through a clean, modern, and interactive interface.

# Kanuu AI Assistant

## Status

Active

## Overview

Kanuu is the intelligent assistant integrated into the portfolio.

It helps visitors learn about Kushagra's work while also providing useful features such as weather information, programming guidance, and portfolio navigation.

---

## Capabilities

- Answers portfolio questions
- Explains projects
- Discusses skills
- Gives weather updates
- Provides current date and time
- Helps navigate the website
- Answers programming questions

---

## Technologies

- Google AI API
- OpenWeather API
- React
- TypeScript

---

## Design Goals

Kanuu was designed to feel professional, helpful, fast, and easy to interact with.

Its primary purpose is to improve visitor engagement without overwhelming the user.
